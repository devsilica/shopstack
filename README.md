🛍️ ShopStack

A premium modern furniture eCommerce application built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

ShopStack delivers a fast, elegant, and responsive shopping experience inspired by premium brands such as Apple, Stripe, and Linear.



✨ Features

- 🏠 Beautiful Landing Page
- 🛋️ Premium Product Catalog
- 🔍 Product Search
- 🏷️ Product Categories
- ❤️ Wishlist
- 🛒 Shopping Cart
- ⚡ Quick View
- ⭐ Product Reviews
- 📦 Checkout Experience
- 📱 Fully Responsive Design
- 🎨 Modern UI & Smooth Animations
  

 🛠 Tech Stack

 Frontend

- Next.js 15 (App Router)
- React
- TypeScript
- Tailwind CSS

 UI

- shadcn/ui
- Lucide React
- Framer Motion
- Sonner

 State Management

- Zustand

 Styling

- Tailwind CSS
- CSS Variables

🚀 Getting Started

 Clone the repository

```bash
git clone https://github.com/devsilica/shopstack.git
```

 Navigate into the project

```bash
cd shopstack
```

### Install dependencies

```bash
npm install
```

or

```bash
pnpm install
```

### Start the development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
